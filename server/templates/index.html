Setting up a Crossway ESV API key

By default, the Bible reader uses free public-domain translations. If you'd rather read and search the ESV, you can add your own free Crossway API key — right from the deck's own ⚙️ Settings button, no file editing needed.

  1. Go to api.esv.org/account and sign up for a free account.
  2. Create a new application to get your API key (Crossway calls this "requesting an API key" — it's free and instant for personal/non-commercial use).
  3. Copy the key it gives you.
  4. Open your deck, click the ⚙️ Settings button in the top bar, paste your key, and save.
  5. The ESV will now show up as a translation option in the Bible reader (R) and Bible overlay (B) — your key is remembered on that browser from then on.
